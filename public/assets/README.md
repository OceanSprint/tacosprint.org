# Logo attribution

`tacosprint.svg` and `../favicon.svg` combine an original taco illustration with
an adapted, recolored Nix snowflake from
[NixOS/nixos-artwork](https://github.com/NixOS/nixos-artwork/tree/master/logo).
The snowflake was originally designed by Simon Frankau and revised by
Tim Cuthbertson. It is licensed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
The adapted snowflake retains that license. Changes include a solid green fill,
scaling, and placement within a taco shell. The taco uses green, white, and red
to match the website’s Mexican flag palette.
